# Smart Waste Scheduler

## Project Overview
Smart Waste Scheduler is a group project developed using Java. It provides a graphical interface for managing waste bins, trucks, and waste collection schedules.

## Features
- Admin and Driver login
- Add and manage waste bins
- Track bin fill levels
- Register waste collection trucks
- Generate a collection schedule for full bins
- Display assigned bins on the Driver Dashboard
- Java Swing graphical user interface

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)
- ArrayList and basic data structures
